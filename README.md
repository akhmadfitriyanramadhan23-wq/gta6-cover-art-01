"Vice Cover" — an offline, deterministic GTA 6 cover-art poster editor. Multi-panel poster, triptych, and single layouts with per-panel cover-fit zoom and offset, three colour grades (Sunset, Neon nights, Vice dusk), bold outlined auto-fit captioning, and one-click PNG export at 1080×1080, 1080×1350, and 1920×1080. No network, no fonts shipped, no Rockstar assets — all original work. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
